# DigitalWallet API

A simple RESTful API built with ASP.NET Core for managing digital wallets and tracking transactions.

## Features
* Wallet management and transaction logging.
* Transaction history with pagination support.
* Unit tests using xUnit and In-Memory Database.
* Automated CI/CD pipeline using GitHub Actions and Newman (Postman).

## Tech Stack
* C# / .NET 8 (or .NET 10)
* ASP.NET Core
* Entity Framework Core
* xUnit & Postman
